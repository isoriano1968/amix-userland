# NEdit for AMIX

NEdit 5.7, a Motif editor, in `/usr/local/bin`: syntax highlighting for C, Makefiles and more, and a Shell menu to run `make`. `nc` opens files in a running NEdit. `make build stage`.

`make stage` also makes the CDE entry: icon, `NEdit` action and an Application Manager file, in `/etc/dt/appconfig`. `build/nedit-amix.tar` holds it all: on AMIX, `cd / && tar xf`. Run `dtappgather` or log in again to see it. The Application Manager entry is under Desktop_Apps.
