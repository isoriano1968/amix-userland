# Halloween intro

An intro drawn on the Z3660's core 1, through `libzzgl.so.1`, with mikmod playing
the music over HDMI: about 56 fps at 866 MHz. `halloween.sh` starts it, from
`/opt/halloween`.

The module is not here: Halloween Bass by dilik, from The Mod Archive (module
208024), goes beside the program as `halloween_bass.it`.
